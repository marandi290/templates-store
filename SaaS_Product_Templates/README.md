# SaaS Product Templates

A set of 10 UI templates for SaaS products, built with modern HTML and responsive CSS.

## Templates

- [SaaS_Starter_UI](./SaaS_Starter_UI/) — SaaS Starter UI
- [AI_Tool_UI](./AI_Tool_UI/) — AI Tool UI
- [CRM_UI](./CRM_UI/) — CRM UI
- [HRMS_UI](./HRMS_UI/) — HRMS UI
- [LMS_UI](./LMS_UI/) — LMS UI
- [Chat_Application_UI](./Chat_Application_UI/) — Chat Application UI
- [Email_Client_UI](./Email_Client_UI/) — Email Client UI
- [Note_Taking_App_UI](./Note_Taking_App_UI/) — Note-Taking App UI
- [File_Manager_UI](./File_Manager_UI/) — File Manager UI
- [Kanban_Board_UI](./Kanban_Board_UI/) — Kanban Board UI

## Usage

Open any `index.html` file in a browser to preview a template.
